# Reflection

One thing I learned while building this site was how much CSS can completely change the feeling of a website. At first I focused mostly on getting things to work, but over time I learned how to make the site feel more polished using cards, hover effects, glowing text, layout spacing, and responsive design. I also learned more about JavaScript by creating an interactive subscribe section that changes after the button is clicked.

I wanted the site to feel magical and creative while still being easy to read and navigate. I used a witchcraft theme with glowing text, dark colors, moon imagery, and themed wording like “new brooms,” but I also made sure the navigation stayed simple and the layout stayed organized. I switched my body font to something more readable while keeping decorative fonts for headings so the site still matched the aesthetic without becoming difficult to use.

I am most proud of how cohesive the final site feels. In the beginning I was mostly focused on finishing the assignment but by the end it started to feel like a real website instead of just a school project. I especially like the resource cards, the footer, the glowing typography, and the interactive subscribe section because they made the site feel more complete and professional.

I think these skills will help me a lot in both game design and graphic design. Learning HTML, CSS, layout design, and user experience helped me understand how visual design and functionality work together. In the future I could use these skills for portfolio websites, game promotion pages, creative projects, or even interactive storytelling experiences.
